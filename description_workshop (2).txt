[h1]Calamity Mod Music[/h1]
[url=https://discord.gg/calamity]Discord[/url] [url=https://calamitymod.wiki.gg]Official Wiki[/url]

[b]This mod adds the Calamity soundtrack and music boxes for each of its songs.[/b] It is intended to be used alongside the Calamity Mod, but can be used alone. You will need to use the Calamity Mod in order to naturally obtain the music boxes.

[i]For Calamity game content, e.g. items and bosses, subscribe to the main mod:[/i]
https://steamcommunity.com/sharedfiles/filedetails/?id=2824688072

[i]For the expanded Calamity soundtrack used for Terraria bosses, biomes and events, subscribe to the vanilla music mod:[/i]
https://steamcommunity.com/sharedfiles/filedetails/?id=2816188633

[b]Be sure to join our Discord server linked above to keep up with the latest news about upcoming updates and features.[/b]
